#  Week 2 – JavaScript Fundamentals & Advanced Concepts
## Topics Covered

* **Variable Declarations:** Scoping rules and hoisting behaviors across `let`, `const`, and `var`.
* **Data Types & Operators:** Primitives, reference types, and expression evaluation.
* **Control Flow:** Conditional branching (`if`, `else if`, `switch`) and iterative loops.
* **Functions:** Declarations, expressions, parameters, and concise **Arrow Functions**.
* **Data Structures:** Working with Arrays and Objects.
* **Advanced Array Methods:** Data transformation and searching using `.map()`, `.filter()`, and `.find()`.
* **ES6+ Enhancements:** 
  * Destructuring arrays and objects for cleaner syntax.
  * Spread (`...`) and Rest (`...`) operators.
* **Scope & Execution:** Global, function, and block scope (lexical scoping).
* **Memory Management:** Understanding **Reference vs. Value** semantics and object mutation.
---

## 💡 Key Learnings & Takeaways

* **Block Scope Mastery:** Eliminated unintended variable leakage by leveraging `let` and `const`.
* **Functional Declarative Code:** Streamlined data processing pipelines using higher-order array methods (`map`, `filter`, `find`) instead of traditional manual loops.
* **Modern Syntax:** Improved readability and parameter flexibility with ES6 destructuring and spread/rest operators.
* **Memory Awareness:** Avoided subtle bugs by understanding how JavaScript handles primitive values (stored by value) versus reference types (stored by reference in memory).
