# Week 1: Things Learnt

## ----- Key Concepts Learned-----

* Understanding how a client (like a web browser) makes HTTP/HTTPS requests to remote servers, and how servers process and return data (HTML, JSON, APIs).
* How human-readable domain names are mapped to IP addresses through root, TLD, and authoritative name servers.
* How network traffic is accurately routed to specific devices and applications using IP addresses and port numbers.
*  Managing local repositories, staging changes, committing history snapshots, and branching strategies for safe collaboration.
*  Connecting local dev environments to GitHub and managing secure pushes and pulls.

---------------------------------------

##  Git Commands Learned

* **Initialize a repository:**
```bash
  git init
```
* **Check repository status:**
```bash
  git status
```
* **Stage your changes:**
```bash
  git add .
```
* **Commit your changes with a message:**
```bash
  git commit -m "your commit message here"
```
* **Connect your local repo to a remote repository:**
```bash
  git remote add origin <repository-url>
```
* **Push your code to GitHub:**
```bash
  git push -u origin main
```
